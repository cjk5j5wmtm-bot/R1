# Fotos de la web de Kansas

Las imágenes actuales de `assets/img/` son fondos de humo y brasas generados
como provisorios. Para poner fotos reales, reemplaza cada archivo por una foto
con **el mismo nombre** (formato `.webp`; si tienes JPG o PNG, Claude las convierte).

| Archivo              | Qué foto va                                   | Formato      |
|----------------------|-----------------------------------------------|--------------|
| `hero.webp`          | Salón o parrilla de noche, ambiente           | Horizontal   |
| `salon.webp`         | Salón o fachada                               | Horizontal   |
| `bar.webp`           | Barra o un cóctel                             | Vertical 4:5 |
| `rib-eye.webp`       | Rib Eye Steak                                 | Vertical 4:5 |
| `hawaiian-steak.webp`| Hawaiian Steak                                | Vertical 4:5 |
| `bbq-ribs.webp`      | BBQ Ribs                                      | Vertical 4:5 |
| `kansas-rolls.webp`  | Kansas Rolls                                  | Vertical 4:5 |
| `cedar-salmon.webp`  | Cedar Plank Salmon                            | Vertical 4:5 |
| `key-lime-pie.webp`  | Key Lime Pie                                  | Vertical 4:5 |

Usa solo fotos propias, del restaurante con su permiso, o con licencia libre.
